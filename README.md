# GenAI-Foundry

An ordered learning repository for generative AI, from model foundations through training, inference, serving, evaluation, RAG, agents, multimodal systems, and experiments.

## Learning Path

1. `01-foundations` - Learn tokenization, embeddings, attention, and transformers.
2. `02-training` - Learn pretraining, fine-tuning, LoRA, QLoRA, and preference tuning.
3. `03-inference` - Learn KV cache, batching, quantization, paged attention, and speculative decoding.
4. `04-serving` - Learn how to serve models with vLLM, SGLang, and distributed inference.
5. `05-evaluation` - Learn benchmarks, hallucination testing, and model evaluation workflows.
6. `06-rag` - Learn retrieval-augmented generation for grounded responses.
7. `07-agents` - Learn tool-using and multi-step agent systems.
8. `08-multimodal` - Learn systems that combine text, image, audio, video, and other modalities.
9. `09-experiments` - Use this area for prototypes, comparisons, and research trials.
10. `10-docs` - Keep guides, notes, and reference material here.
